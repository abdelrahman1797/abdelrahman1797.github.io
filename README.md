# Abdelrahman Hachem — Engineering Portfolio

This package is ready for GitHub Pages.

## 1. Rename your repository

Create a public GitHub repository named:

YOUR-USERNAME.github.io

Replace `YOUR-USERNAME` with your exact GitHub username.

## 2. Upload these files

Upload the CONTENTS of this folder to the root of the repository:

- index.html
- style.css
- script.js
- projects/
- assets/

Do not upload only the ZIP file. GitHub Pages needs the actual HTML/CSS/JS files.

## 3. Replace placeholders

Search the project for:

YOUR-USERNAME
YOUR-EMAIL@example.com
https://www.linkedin.com/

Replace them with your real GitHub username, email address and LinkedIn profile.

## 4. Add your CV

Place your PDF at:

assets/Abdelrahman_Hachem_CV.pdf

The "View CV" button already points there.

## 5. Add project images

Recommended image names:

assets/images/telemedguard-hero.jpg
assets/images/peltier-control-hero.jpg
assets/images/apparatus-control-hero.jpg
assets/images/ros2-scanner-hero.jpg
assets/images/robotic-arm-hero.jpg
assets/images/smart-steering-wheel-hero.jpg

The current project pages contain clean placeholders until you add them.

## 6. Publish with GitHub Pages

For a repository named YOUR-USERNAME.github.io, GitHub normally publishes the main branch automatically.
If needed:

Repository > Settings > Pages > Build and deployment > Deploy from a branch > main / root

Your public URL will be:

https://YOUR-USERNAME.github.io
